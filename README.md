# EVRP
Solving EVRP with RL

## Setup Virtual Environment

1. Install `uv`: [Installation | uv](https://docs.astral.sh/uv/getting-started/installation/)
2. Check `uv` installation by running `uv --version` in terminal.
3. `cd` to the project directory.
4. Synchronize the environment by running: `uv sync`.


## Running the code

1. To train a model, run:
   ```
   uv run train.py
   ```
