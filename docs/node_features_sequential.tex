\section{Node Features by Type}

The heterogeneous GNN state representation uses three node types: \textbf{Truck}, \textbf{Delivery}, and \textbf{Charger}. All features are normalized to facilitate learning.

\subsection{Truck Node Features (13 features)}

Each truck node $i \in \mathcal{T}$ is represented by a 13-dimensional feature vector $\mathbf{f}_i^{\text{truck}} \in \mathbb{R}^{13}$:

\begin{enumerate}[nosep]
    \item \textbf{Node type}: $0 / 3 = 0.0$ (truck identifier)
    \item \textbf{Current position}: $n_i / |\mathcal{V}|$ (normalized node ID)
    \item \textbf{Battery level}: $b_i / B$ (normalized by capacity, kWh)
    \item \textbf{Battery percentage}: $\text{SOC}_i$ (0--1)
    \item \textbf{State: ready}: $\mathbf{1}[\sigma_i = \texttt{ready}]$ (binary, one-hot)
    \item \textbf{State: routing}: $\mathbf{1}[\sigma_i = \texttt{routing}]$ (binary, one-hot)
    \item \textbf{State: waiting\_to\_charge}: $\mathbf{1}[\sigma_i = \texttt{waiting\_to\_charge}]$ (binary, one-hot)
    \item \textbf{State: charging}: $\mathbf{1}[\sigma_i = \texttt{charging}]$ (binary, one-hot)
    \item \textbf{Deliveries completed}: $k_i^{\text{done}} / K_i$ (normalized by total deliveries)
    \item \textbf{Deliveries remaining}: $|R_i| / K_i$ (normalized by total deliveries)
    \item \textbf{Time elapsed}: $t_i^{\text{elapsed}} / T_{\max}$ (normalized by max simulation time)
    \item \textbf{Distance traveled}: $d_i^{\text{traveled}} / 1000$ (normalized in km)
    \item \textbf{Time to destination}: $\max(0, t_i^{\text{arrival}} - g) / T_{\max}$ (only for routing state)
\end{enumerate}

\subsection{Delivery Node Features (3 features)}

Each delivery node $d \in \mathcal{D}$ is represented by a 3-dimensional feature vector $\mathbf{f}_d^{\text{delivery}} \in \mathbb{R}^{3}$:

\begin{enumerate}[nosep]
    \item \textbf{Node type}: $1 / 3 \approx 0.33$ (delivery identifier)
    \item \textbf{Node ID}: $d / |\mathcal{V}|$ (normalized by total nodes)
    \item \textbf{Sequence index}: $\min_{i \in \mathcal{T}} \{ \text{pos}(d, R_i) \} / K_{\max}$ (minimum position across active trucks' remaining deliveries, normalized by max stops)
\end{enumerate}

\subsection{Charger Node Features (4 features)}

Each charger node $c \in \mathcal{C}$ is represented by a 4-dimensional feature vector $\mathbf{f}_c^{\text{charger}} \in \mathbb{R}^{4}$:

\begin{enumerate}[nosep]
    \item \textbf{Node type}: $2 / 3 \approx 0.67$ (charger identifier)
    \item \textbf{Node ID}: $c / |\mathcal{C}|$ (normalized by number of charging nodes)
    \item \textbf{Occupancy rate}: $|\mathcal{O}_c| / \kappa_c$ (current occupancy / capacity, 0--1)
    \item \textbf{Queue length}: $|\mathcal{W}_c| / T$ (waiting trucks normalized by total fleet size)
\end{enumerate}

\section{Edge Features}

All edge types share a common 2-dimensional feature vector $\mathbf{f}_{uv}^{\text{edge}} \in \mathbb{R}^{2}$:

\begin{enumerate}[nosep]
    \item \textbf{Energy cost}: $e_{uv} / 1000$ (kWh, normalized)
    \item \textbf{Time cost}: $\tau_{uv} / T_{\max}$ (hours, normalized by max time)
\end{enumerate}

Edges are only added if the traversal is energy-feasible (accounting for worst-case safety factor $\alpha$).

\section{Global Features}

Two global scalar features are appended to each observation:

\begin{enumerate}[nosep]
    \item \textbf{Global time}: $g / T_{\max}$ (normalized simulation time)
    \item \textbf{Active truck ID}: truck index requiring action at current decision epoch
\end{enumerate}
