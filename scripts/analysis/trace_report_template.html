Choose a scenario, an algorithm and a seed, then drag across the timeline or press play to watch the trucks drive, queue, charge, rest and serve requests. The table at the bottom compares every algorithm on every seed of the chosen scenario.

    Average results over seeds

    One table per scenario: the mean over the seeds each algorithm ran, with the standard deviation after ± for the headline columns. "Finished" counts seeds where every customer was served and every truck returned; "Served %" is customers served in static scenarios and requests delivered on time in request scenarios; "Stranded runs" counts seeds where a truck was left with no feasible action. The best value in each column is highlighted: highest for Finished and Served %, lowest for the others. Columns that are zero for every algorithm are left out. Select an algorithm's name to open its first run.

    Regenerate or extend with python -m scripts.analysis.trace_report run --scenario NAME=CONFIG --seeds … --policy … --out traces.json, then render traces.json [more.json …] --html report.html. Map legs are straight lines between stops; the simulator drives the minimum-energy road path.
